# Initial Project Ideas:

## Idea 1
Reformat Pokerus to use React+Vite and flesh out to be much more easily modified+expanded. Build it from scratch and add a battle simulator. [pokeapi link](https://pokeapi.co/?ref=public_apis&utm_medium=website)
Components starting point:
1. PokemonComponent
2. ListComponent
3. MovesComponent
4. BatllersComponent
5. StageComponent
6. BattleSimulator
May need an animation component

## Idea 2
Using [mtgjson](https://mtgjson.com/) We create a React+Vite magic the gathering card catalogue that allows users to search for cards, place in decks, and will verify which formats the deck is legal as well as let users know what is missing or needs to be removed to make it legal for a selected format. Many like this are out there, but would be a fun project to eventually incorporate a description search in case you can only remember what the card art looks like. I.e. Red hair, women would pull up every card with a picture of a red haired woman as the art. 
Components starting point:
1. CardComponent
2. ListComponent(For search results)
3. DeckComponent(For saved lists)
4. LegalComponent

## Idea 3
 On public API there is a Dungeons and Dragons. USing that API, we create a player character creator that allows for users to pull from common information like levelups, stat rolling, and HP calculations to set up their character while also providing links to backstory helpers.
Components:
1. CharacterSheet
2. Class
3. LevelUp
4. SetUplvl1
